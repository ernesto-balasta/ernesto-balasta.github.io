# Ernesto Balasta – Portfolio

Static website for GitHub Pages. No build step: upload the files as they are.

- `index.html` – home page
- `case-studies/` – six case-study pages
- `css/style.css` – all styles (colors, Poppins type, layout)
- `images/` – add your screenshots and headshot here (see `images/README.txt` for file names)
- `files/` – add your resume PDF here (see `files/README.txt`)

To change text, open the `.html` file on GitHub, click the pencil icon, edit the words between the tags, and click **Commit changes**. The site updates in about a minute.
