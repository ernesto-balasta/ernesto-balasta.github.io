Returns SOP across three marketplaces

I handle customer returns for ANWB and Obelink (Mirakl marketplaces) and Bol.com, and wrote the procedures as versioned SOPs with video walkthroughs.

Type
Professional work, Sunflake
Frequency
Daily (ANWB, Obelink); 3× a week (Bol.com)
Tools
Outlook, Commercium, Picqer, Returnless, Claude, Loom
Rule
Label the same working day

Business context

Customers of ANWB and Obelink can't create a return label themselves. Sunflake has to create it and email it, and the order number a customer quotes is not the one the returns system needs.

Problem

Without a fixed process, returns could wait days, labels could go to the wrong order, and damaged-item claims could get a label when they needed the owner.

My role

I own the daily process and the documents. Anything that isn't a standard return goes to the owner the same day, with no label made.

Objectives

Same-day labels for standard returns, no paid shipping options picked by mistake, and every exception escalated.

Process

Each morning a Claude check summarizes new return emails and pre-fills the reply template. I work through them like this:

  1. 1. Return email arrives. No order number? Send the “ask for order number” template and wait for the reply.
  2. 2. Standard return? Exchange, damaged item, wrong product or complaint: no label, report to the owner the same day.
  3. 3. Find the order in Commercium or Picqer, and note the reference and marketplace email the returns system needs.
  4. 4. Create the return in Returnless: free print-a-label option, no paid protection, total €0.00.
  5. Order still not found after a second try? No label; report to the owner.
  6. 5. Email the label with the Dutch template and the customer's own order number, then mark the email as done.

Deliverable

Result

Anyone can repeat the process: which order number goes where, which return reasons stop it, and what an escalation message must contain.

Key learning

The most useful part of an SOP is the exceptions table. Knowing when not to act is what protects the business.
